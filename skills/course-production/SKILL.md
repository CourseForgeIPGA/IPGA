# Course Production

Input: a completed `curriculum.md`. If missing, run `curriculum-design` first.

## Step 1 - Script each lesson
For each lesson, fill `templates/lesson-script.md`:
- Hook (15-30 sec): why this lesson matters
- Teach: the core idea in 3 points max
- Show: a demo, example or story
- Do: the action step
- Bridge: tease the next lesson

Write in the expert's voice. Keep scripts as bullet prompts unless the expert asks for word-for-word.

## Step 2 - Supporting assets
Per module, list what's needed: slides, worksheets, templates, checklists, quizzes. Draft worksheet and quiz content directly.

## Step 3 - Recording setup (budget tiers)
- Starter: phone or webcam, lav mic, window light, free editor (CapCut, DaVinci Resolve)
- Mid: USB mic, 1 key light, screen recorder (OBS, Loom)
- Pro: mirrorless camera, XLR mic + interface, 2-light setup

Recommend the cheapest tier that fits the format. Audio quality matters more than video.

## Step 4 - Production schedule
Fill `templates/production-plan.md`: batch recording by module, editing, upload, QA. Default pace: 1 module per week.

## Step 5 - Quality check
- Every lesson has an action step
- Audio is clear, captions exist
- File naming: `M01-L01-lesson-title`

Then suggest moving to the `backend-setup` skill.
